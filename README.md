# OurC-Interpreter
In Project2 of the OurC interpreter development, I implemented the lexical analyzer and syntax parser based on the EBNF grammar specification of the OurC language. This part focuses on breaking down the source code into valid tokens and parsing the structure according to the language rules.

Key features completed in this stage include:

Lexical analysis: Identification and categorization of tokens such as keywords, identifiers, literals, operators, and delimiters.

Syntax parsing: Construction of a parse tree (or abstract syntax tree) that accurately represents the hierarchical structure of OurC programs.

Error handling: Basic detection and reporting of syntax errors with informative messages to help debugging.

This phase sets the foundation for the next stages of the project, where semantic analysis and interpretation will be added. It ensures that any given OurC program can be correctly tokenized and parsed before interpretation.
